# Surface brief: gate web app (live gate view first)

Mode: Operate. Scope: the whole web app's visual world, built first on the Live gate view (new home), then carried through Review queue, truck detail, Camera, phone capture (backup), test read, login.
Audience and job: office operator at a desk PC, day and night shifts, confirms or corrects each truck's read; owner checks the gate; visiting depot owners must find it impressive, then trustworthy, then simple.
Must not feel: generic template, playful/colourful, cluttered, old-fashioned grey.
Chosen direction: Terminal Safety Signage. Memorable moment: the live camera with its GATE lane plate beside the current number set large on a safety-blue sign plate, check digit boxed.
Unresolved: product brand name (working name "Depot Gate"); Reports/Settings pages do not exist yet and are not shown.

## Direction contract

THESIS: The gate reads like the terminal's own signage: every truck's state wears the ISO safety colour the yard already obeys (green confirmed, yellow needs a person, blue act now, red refused, grey no container). Refuses the category default of a white card dashboard with a blue primary and pastel status pills.

OWN-WORLD: Graphite asphalt rail (#1E2226) and porcelain work ground (#F4F4F1), 1px warm-grey rules (#CBCBC3) forming the grid; ISO safety colours used only as state: green #0F8A4B, signal yellow #F2C200 (only where a person is needed), safety blue #1F5FA8, prohibition red #C8202A, neutral #6C7378. One family, Barlow Semi Condensed, carries display and data, tabular numerals. Enamel sign plates with a double inner keyline and rounded corners for lane and number plates; boxed check digits everywhere a number appears; flat, no gradients, no glows. Raised: one type family on a 1px rule grid; fixed row furniture; gate time against target on every truck; hard state switches.

STORY: The operator sees at a glance what the gate is doing now and what needs them: the truck at the gate, its read and why it is trusted, and the day's flow. They confirm or correct in one action and trust the record because the proof sits next to the number.

FIRST VIEWPORT: Left graphite rail (wordmark, nav with yellow review count, language switch, camera and engine status). Work area: title row with state key; today strip of four counts plus average gate time against the 60 s target bar; live row with the camera (GATE 1 lane plate top-left, LIVE badge top-right, detection and photo/read progress overlay bottom) and to its right the current read panel: sign plate with the number and boxed check digit, validity line, four facts, Confirm (safety blue) and Correct number; below, Recent visits rows with a left state bar, fixed columns time / container / type / state / gate-time bar with a target tick.
